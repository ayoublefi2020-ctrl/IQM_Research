Can a quantum memory keep its state?

We stored one logical qubit on IQM Emerald and counted how often we could recover its value after repeated error checks.

Superconducting processors can already demonstrate error suppression. On Willow, researchers measured a lower logical error per cycle as they enlarged their surface code. Our question was whether a larger code would help on Emerald, with its own connections and gate errors. Read the Willow experiment

Our experimental framework

We describe one memory in Python, translate it through Qiskit or Qrisp, and check the compiled circuit against the original measurement parities. Select a stage to follow the experiment from circuit design to a decoded shot.

    Which qubits can interact on Emerald?

    A dot is a physical qubit. A line joins two qubits that can perform a controlled-Z (CZ) gate directly in the saved calibration. Our circuits use CZ gates to couple data qubits to the helpers that check them.

    The highlighted 17-qubit patch supports every required distance-3 interaction. When a pair has no direct link, routing can move quantum information through other qubits using SWAP gates. Those extra operations introduce more opportunities for error.

    Does a larger code protect the memory better?

    Both patches store one logical qubit. The distance counts the fewest single-qubit Pauli errors that can combine into an undetected logical operation. With ideal checks, distance 3 can correct any one such error and distance 5 can correct any two.

    What the same codes do in simulation

    These curves use the same assumed balanced noise on both logical circuits. They let us study code size without the extra gates needed to route the hardware jobs.
