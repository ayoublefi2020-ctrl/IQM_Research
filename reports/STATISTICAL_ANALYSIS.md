# Statistical analysis

Logical failure is the fraction of shots in which the decoder prediction differs from the measured logical parity. The website uses 95% Wilson binomial intervals for shot uncertainty. These intervals do not include calibration drift or correlations within randomized blocks. Re-decoding is displayed with its own result row while physical shot totals count the underlying execution once.

Use comparable circuits, round counts, calibrations and decoders for conclusions. The archived fit files preserve the original fit parameters. A fitted per-cycle value requires a round sweep with acceptable fit quality. The site displays measured points as the primary result and leaves fits off the mixed-run plots.
